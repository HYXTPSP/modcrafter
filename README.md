# ModCrafter 模组工坊

<p align="center">
  <img src="assets/logo.png" width="128" alt="ModCrafter Logo">
</p>

**在 Minecraft 里制作 Minecraft 模组。**

这是一个 Fabric 模组(MC 1.21.1),让你不写一行代码、不离开游戏,
就能制作自己的"迷你模组"(内容包):自定义物品、方块、合成配方、事件逻辑,
自带 16×16 像素画板画贴图,大部分内容即时生效,还能一键导出成
**真正的、可独立编译分发的 Fabric 模组工程**。

## 功能一览

| 功能 | 说明 |
|---|---|
| 自定义物品 | 普通物品 / 食物 / 剑 / 镐 / 斧 / 铲 / 锄 / **盔甲四件**(头盔·胸甲·护腿·靴子,7 种盔甲材质),可调堆叠、耐久、稀有度、防火、附魔光效、提示文字、食物营养、工具材质与攻击属性 |
| 自定义方块 | 硬度、抗爆、亮度(发光)、音效、透明方块、滑度(冰面效果)、挖掘工具类型与等级、掉落物、矿石世界生成;外观支持**单一贴图 / 六面不同贴图 / 体素 3D 模型**,并可设置**朝向**(无 / 水平四向像熔炉 / 六向像投掷器),非满格模型自动获得贴合的碰撞与选择框 |
| 自定义配方 | 工作台有序/无序、熔炉、高炉、烟熏炉、**切石机**,3×3 可视化摆放 |
| 事件逻辑 | 8 种触发器(右键物品、攻击生物、吃食物、**手持每秒**、挖方块、右键方块、踩方块、**放置方块**) × 16 种动作(消息、药水效果、爆炸、落雷、执行命令、给物品、播声音、弹射、治疗、伤害、点燃、**生成实体、给经验、相对传送、设天气、播粒子**) |
| 贴图 | 113 张内置预设 + 16×16 像素画板(固定调色板 + **RGB/十六进制自定义颜色 + 取色器 + 12 个持久化自定义色槽**) + **从电脑导入 PNG/JPG**(自动裁剪缩放,右键已画贴图可再编辑) |
| 热加载 | 新物品/方块在单人游戏中即时注册生效,**物品栏图标即时显示**;名称/贴图/配方/掉落/事件即时刷新 |
| 分享 | 一键导出内容包 zip,朋友(装有本模组)丢进文件夹即用 |
| 导出模组 | 一键生成完整 Fabric 工程(含 Gradle wrapper 和小型运行时),`gradlew build` 即得独立 jar,**不依赖本模组** |

## 构建本模组

需要 **Java 21**,首次构建需联网下载依赖:

```bash
./gradlew build        # Windows 用 gradlew.bat build
```

产物: `build/libs/modcrafter-0.3.0.jar`(不要用 -sources 那个)。

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)(MC 1.21.1)
2. 把 [Fabric API](https://modrinth.com/mod/fabric-api) 和本模组的 jar 放进 `mods` 文件夹

## 使用教程

1. 进入单人游戏,按 **K**(或输入 `/modcrafter`)打开工坊
2. **新建内容包** —— 包 ID 就是你模组的命名空间,比如 `mypack`
3. 在 物品/方块/配方/事件 标签页里点"新建",填表单、选贴图(或打开画板自己画)
4. 点 **保存并应用** —— 新物品立刻注册进游戏:创造物品栏搜索,或 `/give @s mypack:物品ID`
5. 想要逻辑?建一个事件:比如"右键使用 红宝石剑 → 落雷 + 播放声音"
6. **导出** 页里:
   - `导出分享包(.zip)` → 发给朋友,丢进他的 `config/modcrafter/packs/` 即可
   - `导出独立 Fabric 模组工程` → 在 `config/modcrafter/exports/<包ID>_mod/` 生成完整工程,
     电脑上运行 `gradlew build` 得到独立 jar,可以发布、可以不装 ModCrafter 直接用

### 文件位置

```
config/modcrafter/packs/<包ID>/pack.json        # 内容包定义(JSON,可手改)
config/modcrafter/packs/<包ID>/textures/*.png   # 自定义贴图(16×16)
config/modcrafter/exports/                      # 导出产物
resourcepacks/ModCrafter/                       # 自动生成的资源包(勿手改)
<存档>/datapacks/ModCrafterData/                # 自动生成的数据包(勿手改)
```

## 已知限制(v0.3)

- **热注册仅限单人游戏**;在多人服务器上,双方都装模组 + 相同内容包,重启后生效
- 修改**已存在**物品的类型/耐久/食物数值等"注册期属性"需要重启游戏(名称、贴图、提示文字、配方、掉落、事件即时生效)
- 删除元素后,已注册的物品要重启才会真正消失
- 热注册的新物品要**重进世界**才会出现在创造物品栏里(但 /give 和配方立即可用,图标正常显示)
- **矿石生成需要重进世界后生效**,且只在新生成的区块中出现(这是 MC 世界生成的机制)
- 盔甲穿戴外观支持任意颜色染色与自定义护甲层贴图;**穿戴 3D 体素模型**(随四肢运动)属于下一阶段
- 体素模型的碰撞箱是模型包围盒(单个长方体),非逐体素精确碰撞;32³ 模型请用大色块,过于细碎会超出元素上限
- 若热注册失败(比如与其它注册表相关模组冲突),会自动降级为"重启后生效",数据不会丢

## 更新日志

### v0.3.0
- **体素建模器(重头戏)**: 在游戏里像搭积木一样给方块/物品建 3D 模型
  - 切片式编辑(逐层俯视绘制,滚轮换层,半透明显示下一层轮廓) + 可旋转等轴 3D 实时预览
  - 分辨率 8³ / 16³ / 32³;调色板复用画板全套(固定色+RGB/十六进制+取色器+自定义色槽),每模型最多 62 色
  - 保存时自动"贪心合并"成原版 JSON 模型(相邻同色合并成大长方体 + 单像素 UV 调色板贴图),被遮挡面剔除,元素超限会提示
  - 模型存在模型库里,可反复编辑,多个方块/物品可共用;编辑后"应用"即全部刷新
  - 方块用模型: 物品栏按标准方块视角显示;非满格模型自动贴合碰撞/选择框并按朝向旋转
  - 物品用模型: 剑/工具/普通物品拿在手里就是立体模型
- **方块六面贴图**: 上下北南东西各选一张贴图,可一键"应用到全部"
- **方块朝向**: 水平四向(放置时面向你,像熔炉)或六向(像投掷器),模型/贴图/碰撞箱同步旋转
- **盔甲穿戴外观**: ①任意颜色染色(皮革布局+染色组件,护甲数值仍按所选材质,自动加入 dyeable 标签);②导入自定义 64×32 护甲层贴图(层1=头盔/胸甲/靴子,层2=护腿),自动注册专属盔甲材质
- 导出的独立模组完整支持以上全部(包围盒导出时预计算,内置于 jar)

### v0.2.0
- **修复: 热注册物品的物品栏图标不显示、需要重启的问题**(根因: 原版 ItemRenderer 启动时快照物品模型映射;现在每次应用更改时把新物品补进映射)
- 新物品类型: 锄、头盔、胸甲、护腿、靴子(7 种盔甲材质可选)
- 方块: 矿石世界生成(矿脉大小/每区块数量/Y 范围)、透明方块、滑度
- 配方: 切石机
- 触发器: 放置方块时、手持物品每秒
- 动作: 生成实体、给予经验、相对传送、设置天气、播放粒子
- 画板: RGB/十六进制自定义颜色、取色器、12 个持久化自定义色槽;右键自定义贴图可重新编辑
- 贴图: 支持从电脑导入 PNG/JPG(自动居中裁剪 + 缩放到 16/32/64/原始尺寸)

## 技术说明

- 游戏内热注册通过 Mixin 访问器临时解冻 `SimpleRegistry`(`frozen` / `intrusiveValueToEntry`),
  注册完成后立即重新冻结;失败时优雅降级
- 资源(模型/贴图/语言)生成到 `resourcepacks/ModCrafter` 并自动启用;
  数据(配方/战利品表/标签)生成到世界 `datapacks/ModCrafterData` 并自动 reload
- 导出的独立模组内置一个 ~4 个类的小型运行时,从打包进 jar 的 `pack.json`
  注册内容并执行事件,不依赖 ModCrafter
